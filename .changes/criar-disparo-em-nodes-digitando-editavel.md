titulo: Criar fluxo de disparo agora é no editor em estilo nodes, com segundos editáveis
---

O botão "Novo fluxo de disparo" não abre mais o formulário antigo: ele leva para uma página de criação com o mesmo layout em estilo nodes do editor (breadcrumb "‹ Fluxos / Novo fluxo de disparo", painel à esquerda, cartões Início → imagem → digitando → texto → Fim). Criar e editar ficaram o mesmo lugar, e a edição rápida da lista também abre o editor. Função nova: o "Digitando por N segundos" é editável (0–5 s) e vale no disparo de verdade — antes era fixo em 2,6 s. Os formulários antigos em dialog foram removidos.
